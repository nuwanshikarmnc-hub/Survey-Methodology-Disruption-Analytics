# Survey-Methodology-Disruption-Analytics
Evaluating the academic, technical, and psychological impacts of the 2024 non-academic strike on Faculty of Science undergraduates at the University of Kelaniya using SPSS and stratified sampling

Tools & Technologies
Statistical Analysis: IBM SPSS Statistics   
Data Collection: Google Forms, Microsoft Outlook, WhatsApp   
Documentation: MS Excel, MS PowerPoint   

Methodology & Data CollectionTarget Population: N = 1,884 students across 9 degree programs.  
Sampling Technique: Stratified random sampling with proportional allocation.  
Response Rate: 280 completed responses (87.5% response rate)

Key FindingsTechnology: 
1. Device access was strong (88%), while lab software installation was the lowest rated (52%).  
2. Online Learning: Recorded lectures were helpful (54%), but live lecture concentration was low (24%).
3. Psychological Strain: 65% experienced disconnection, 56% sleep disruption, and 55% loneliness.
4.  Academic Recovery: Accelerated calendars caused stress for 64%, with only 34% reporting adequate exam prep time.
